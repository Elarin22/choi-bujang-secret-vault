# 내 보안 Agent 시작 틀 0.2.11

이 보안 Agent는 회사 직원이 자기 로그인 상태, 업무 앱 접속 결과, 최근 접속 기록과 보안 경보를 보는 보안 앱입니다. 13단계부터 22단계까지 이 프로젝트 하나로 화면을 채워 가며 완성합니다. 처음이라면 docs/GETTING_STARTED_STUDENT.md부터 읽습니다. 무엇을 왜 만드는지와 단계별 순서가 그 문서에 있습니다.

이 시작 틀을 받은 것만으로 단계를 통과하지 않습니다. 단계마다 docs/STUDENT_PROMPTS.md의 안내를 수업용 AI에 붙여 넣어 student/extension.mjs를 고치고, 화면에서 확인하고, 커밋한 뒤 ALEPH에 제출합니다. 제출하면 서버가 그 커밋의 코드를 받아 AI가 단계 과제 기준으로 읽고 판정합니다. 코드를 실행해서 판정하지 않습니다.

## 켜기

검수 환경은 Node.js 24.19.0이며 외부 npm 의존성이 없습니다. 이 폴더의 PowerShell에서 아래를 실행하고 PC 브라우저로 http://127.0.0.1:5189 를 엽니다. 자세한 켜기·끄기·다시 켜기는 docs/STUDENT_LAUNCH_GUIDE.md에 있습니다.

    powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1

npm start도 같은 서버를 켭니다. 기본 실행은 실제 회사 시스템(기존 엔진)에 연결되지 않은 상태입니다. npm run demo는 예제 자료로 화면을 보여 줄 뿐이며 실제 연결이나 성취가 아닙니다. npm run check는 student/extension.mjs의 문법만 확인합니다.

## 지킬 것

- 기존 1~3차 프로젝트와 학생 파일은 지우거나 덮어쓰지 않습니다. 새 폴더에서 시작하거나, 이미 하던 프로젝트를 이어 씁니다.
- AI 열쇠·비밀번호·토큰을 코드, 커밋, 캡처, 도움정보에 넣지 않습니다. 주소나 열쇠를 직접 입력하는 칸도 만들지 않습니다.
- .env.example에는 비밀 없는 설정만 있습니다.

## Heeeyaazz 대시보드

보호 현황 첫 화면에는 사용자·세션, 현재 기기, 업무 앱 판정, 연결·자료 상태를 요약합니다. 아래 기록 추이는 제공된 최근 최대 40건을 날짜별로 집계하며 새 탐지를 수행하지 않습니다. 최근 기록과 상태 값은 서버 응답에서 읽습니다. `demo` 모드에는 예제 자료 표식을 붙이고 실제 연결 자료와 구분합니다. 고정 예시 숫자나 예제 사용자를 실제 측정값처럼 표시하지 않습니다.

`내 PC 상태`는 로컬 Node.js 프로세스가 기본 `node:os` 및 `node:fs` 읽기 API로 CPU 표본(1초 구간), 물리 메모리, 시스템 드라이브의 비관리자 사용 가능 공간을 조회합니다. 브라우저의 최초 로드와 사용자가 누르는 `다시 불러오기` 때만 한 번 측정합니다. 각 값에는 측정 시각과 단위를 표시하고, 읽지 못한 값은 이유와 함께 `확인 불가`로 표시합니다. 이 정보는 브라우저와 `127.0.0.1` 로컬 서버 안에서만 처리하며 저장하거나 외부로 보내지 않습니다. PC 상태 값은 `demo`의 예제 사건·사용자와 별개인 실제 로컬 측정값입니다. 이번 화면은 단일 측정 설명만 제공하며, 측정 이력이나 과거 자원 추이는 저장하지 않습니다.

같은 `내 PC 상태` 영역은 PowerShell의 읽기 전용 .NET 네트워크 인터페이스 조회, `Get-NetFirewallProfile`, `Get-WinEvent`를 사용해 네트워크 인터페이스·주소·게이트웨이·DNS, 방화벽 프로필, 최근 24시간 System·Application 로그의 경고·오류 건수를 표시합니다. 관리자 권한을 요청하거나 방화벽 설정을 변경하지 않습니다. 현재 사용자에게 조회 권한이 없거나 Windows API가 값을 제공하지 않으면 항목별 이유와 `확인 불가`를 표시합니다. 이벤트 메시지나 원문은 읽어 화면에 표시하거나 저장하지 않으며, 건수는 침해·공격 탐지 결과가 아닙니다. SDP 연결 상태는 이 로컬 PC 조회와 별도 상태로 표시합니다. SDP 어댑터가 없으면 `SDP 미연결`, 설정만 있고 현재 응답을 검증하지 못했으면 `SDP 연결 확인 불가`입니다.

## 기본 패키지와 사용자 단위 설치

필요 런타임은 `package.json`의 Node.js `24.19.0`입니다. 설치 프로그램은 Node.js를 포함하거나 설치하지 않습니다. 대상 PC에도 같은 버전을 준비해야 합니다. 앱은 로컬 웹 서버로 동작하므로 시작 메뉴의 Heeeyaazz 항목을 실행한 뒤 PowerShell에 출력된 로컬 주소를 브라우저에서 엽니다. 앱 종료는 시작한 PowerShell 창에서 `Ctrl+C`를 누릅니다.

기본 ZIP과 Inno Setup 설치 프로그램을 만들려면 앱 폴더에서, 비어 있거나 아직 없는 별도 출력 폴더를 지정해 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\package-heeyaazz.ps1 -OutputDirectory 'C:\경로\새-출력-폴더'
```

위 `C:\경로\새-출력-폴더`는 **명령 형식 예시**이며 실측 경로나 이미 만들어진 결과가 아닙니다. 스크립트는 기존 출력물을 덮어쓰지 않습니다. 기본 ZIP은 `Heeeyaazz-0.2.11-portable.zip`으로 생성됩니다. Inno Setup 컴파일러 `ISCC.exe`가 현재 PowerShell의 PATH에서 확인될 때만 `Heeeyaazz-Setup-0.2.11.exe`도 만듭니다. 설치 후 찾지 못하면 컴파일러 설치 폴더를 현재 PowerShell 세션 PATH에 추가하고, 새 빈 출력 폴더를 지정해 다시 실행합니다. 현재 저장소에는 Inno 스크립트만 포함하고 컴파일된 실행 파일은 커밋하지 않습니다.

Inno Setup은 `{localappdata}\Programs\Heeeyaazz`에 사용자 단위로 설치하며 관리자 권한을 요청하지 않습니다. 포장은 공개 앱 파일·소스·학생 렌더러·시작 도구만 포함합니다. `.env`, 개인 인증 자료, 데이터베이스, Git 기록, 과제 제출 묶음은 패키지에서 제외합니다. 이 프로그램은 브라우저에서 여는 로컬 웹 앱이며 Windows 네이티브 보안 스캐너가 아닙니다.

### 값의 출처

- **실제 연결 자료:** 화면이 현재 서버에서 받은 값만 표시합니다. 연결·조회가 실패하면 실패 또는 확인 불가를 표시하며 이전 값을 유지하지 않습니다.
- **예제 자료:** `npm run demo` 또는 시작 도구의 `-Demo`에서 나온 값은 `예제 자료(demo)`로 표시합니다. 실제 사용자, 실제 측정 결과, 운영 보안 상태가 아닙니다.
- **추이 수치:** 현재 전달받은 기록 배열의 건수만 계산합니다. 전체 로그 건수나 기간 전체의 추세로 확대 해석하지 않습니다.
